# BS_FCSplash
Adds a splash animation at the end if you FC a song with custom picture support

#####################################

VERY EARLY STAGES
####################################
Usage:
1. Create a folder in UserData named "FCSplash"
2. Put any single image you want as the splash image in it
3. FC a song and profit
####################################
Please disable bloom as images will be a white bright box with it enabled
