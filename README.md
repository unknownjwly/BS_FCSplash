# BS_FCSplash

> **Adds a splash animation at the end if you FC a song with custom picture support.**

[![Status](https://img.shields.io/badge/status-very%20early%20stages-orange)]()

</div>

---

## Usage

1. Create a folder named `FCSplash` inside your `UserData` directory.
2. Place any single image you want to use as your splash screen inside that folder.
3. Full Combo (FC) a song.
